# S&S Computer Repair - Modern Single-Page Website

## Overview
This is a modernized, single-page website for S&S Computer Repair business. The website has been completely redesigned from a multi-page structure to a modern, responsive single-page application with enhanced user experience and professional design.

## What Changed

### ✅ Modernization Features
- **Single-Page Design**: Consolidated all content into one page with smooth scrolling navigation
- **Modern UI/UX**: Clean, professional design with Bootstrap 5 and custom CSS
- **Responsive Design**: Mobile-first approach with excellent mobile experience
- **Smooth Animations**: CSS animations and JavaScript interactions for enhanced engagement
- **Professional Typography**: Modern font stack using Inter font family
- **Icon Integration**: Font Awesome icons for visual appeal

### ✅ Content Consolidation
- **Home Section**: Hero section with company introduction and call-to-action buttons
- **Services Section**: Comprehensive list of computer repair services with visual cards
- **About Section**: Company information and owner details
- **Contact Section**: Contact form and business information with embedded map
- **Removed**: Computers section (as requested)

### ✅ Technical Improvements
- **Bootstrap 5**: Latest Bootstrap framework for modern components
- **Modern JavaScript**: ES6+ features with enhanced functionality
- **Performance**: Optimized loading and smooth scrolling
- **Accessibility**: Enhanced keyboard navigation and screen reader support
- **SEO Ready**: Proper HTML structure and meta tags

## Setup Instructions

### 1. Prerequisites
- Modern web browser
- Local web server (for development)
- Text editor or IDE

### 2. Installation
1. Clone or download the project files
2. Ensure all files are in the correct directory structure
3. Open `index.html` in a web browser

### 3. Development Server (Optional)
For local development, you can use:
```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .

# PHP
php -S localhost:8000
```

### 4. Customization
- **Colors**: Modify CSS variables in `css/style.css`
- **Content**: Edit text content in `index.html`
- **Images**: Replace images in `img/` folder
- **Contact Form**: Update form action in contact section
